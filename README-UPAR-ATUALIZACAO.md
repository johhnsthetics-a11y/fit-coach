# Como subir esta atualização

1. Extraia o arquivo `.zip`.
2. Abra a pasta extraída.
3. No GitHub, envie os arquivos da raiz junto com as pastas `src`, `public` e `supabase`.
4. Mantenha os arquivos dentro das pastas. Exemplo: `src/App.jsx` precisa continuar dentro da pasta `src`.
5. Depois de subir, aguarde o Cloudflare fazer o deploy.

## O que mudou nesta atualização

- O painel verifica a assinatura automaticamente quando o treinador volta do checkout.
- A tela de assinatura ficou mais clara após o pagamento.
- O botão de pagamento agora usa uma mensagem mais simples: `Verificar pagamento agora`.
- O app mantém o provedor de cobrança pronto para a migração para Cartpanda.
- Textos antigos e termos técnicos foram revisados.

## Importante

No checkout, o treinador precisa usar o mesmo e-mail cadastrado no FIT COACH. Assim o sistema consegue reconhecer o pagamento e liberar o painel automaticamente.
